How to read the visualization

  • Bucket: The array position calculated by the hash function.
  • Node: A food item stored in the hash table.
  • Arrow: The link to the next node in the chain.
  • NULL: The end of the linked list.
  • Collision: Multiple food IDs map to the same bucket.
