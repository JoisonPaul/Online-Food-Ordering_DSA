How Hashing Works

Every available food item is indexed using its integer Food ID as the key. The modulo division hash function determines the target bucket index in constant time.

Hash Function Formula index = Food_ID % Capacity (10)

When two or more items map to the same bucket index (e.g. ID 101 and ID 111 both yield 1), separate chaining links them in a singly-linked list at that bucket slot.

Core DSA Operations

1. Insertion

O(1) time complexity. Computes bucket index and prepends node to chain head.

2. Searching

O(1) average time. Hashes key and traverses only the target short bucket chain.

3. Collision Handling

Separate chaining preserves all colliding entries without clustering artifacts.

4. Deletion

O(1) average time. Unlinks sold-out food items from the bucket linked list.
